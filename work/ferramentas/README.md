# Ferramentas

- `publicacao/preparar-publicacao.cjs`: prepara uma saída pública a partir de duas pastas informadas.
- `laboratorio-luz/`: palco local para testar clipes de luz e cor. Abra `laboratorio-luz/index.html`. Não entra no pacote público.
- `verificacao/`: verificadores existentes; usam `work/catalogo-web` por padrão e aceitam caminho alternativo como argumento.
- `migracoes/`: scripts antigos, organizados pelo assunto das intervenções. Eles podem depender de trechos já alterados; revise cada script antes de reaproveitar.

Execute comandos a partir da raiz do projeto para que as pastas de saída documentadas sejam fáceis de localizar. Antes de compartilhar um pacote, confira o destino e envie apenas o conteúdo público gerado.
