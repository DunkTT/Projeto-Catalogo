# Pesquisa auxiliar de produtos

Esta pasta guarda material de pesquisa e curadoria auxiliar do catálogo: páginas de referência, resultados, imagens, scripts e arquivos de validação. As subpastas `images/`, `qa/` e `similar/` agrupam materiais visuais, conferências e comparação de itens.

Os scripts aqui foram criados como ferramentas locais e podem abrir arquivos por caminhos relativos. Execute-os a partir desta pasta e consulte os parâmetros e caminhos no próprio script antes de mover conteúdo. O site ativo é mantido separadamente em `../catalogo-web/`.
