# Catálogo ULTRALED Hortolândia

## Onde começar

- A Home e o catálogo mantidos como fonte estão em `work/catalogo-web/`.
- A página de entrada deste projeto está em `index.html`.
- Publicações anteriores e seus pacotes ficam agrupados por versão em `work/versoes/`.
- Ferramentas e instruções estão em `work/ferramentas/` e `work/documentacao/`.
- O material de pesquisa de produtos e imagens fica em `work/catalogo/`.

Leia primeiro [`work/README.md`](work/README.md) para entender os caminhos. A organização do código ativo está em `work/catalogo-web/ORGANIZACAO.md`.

Para retomar o trabalho em outra máquina ou sessão, leia [`work/documentacao/CONTINUIDADE-NUVEM.md`](work/documentacao/CONTINUIDADE-NUVEM.md) e [`AGENTS.md`](AGENTS.md). O arquivo `config-codex-exemplo.toml` contém somente as configurações reproduzíveis, sem credenciais.
